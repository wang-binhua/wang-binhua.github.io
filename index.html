Campus Finance

一个面向个人日常记账的 Windows 桌面与本机 Web 项目。 记录收支、查看历史和月度变化，并把账本数据保存在本机。

查看源码 ↗ 了解项目

这是项目介绍页，不提供在线记账服务。应用默认只监听本机地址，账本不会托管在此网站上。

WHAT IT DOES

从日常记录到月度回顾

01

收支与历史

记录收入、支出、类别、时间和备注；查询历史账目并按月导出 CSV。

02

预算与余额

按类别设置月度预算，并以余额快照为基准累计之后的收入与支出。

03

桌面与本机网页

提供原生 Windows 桌面界面和本机 Web 界面；两者使用本机账本数据。

UNDER THE HOOD

项目技术

技术栈

  • C17
  • Win32 API
  • SQLite / SQLCipher
  • OpenSSL
  • HTTP / JSON
  • HTML · CSS · JavaScript
  • CMake
  • CTest

工程实践

  • 数据库凭据与账本分离保存，账本使用 SQLCipher 加密。
  • 本机服务限制回环地址，并对数据接口执行认证和请求来源校验。
  • 使用独立临时数据库编写安全与功能回归测试。
  • 通过 CMake 构建桌面程序和本机 Web 服务。

这是一个持续学习与维护中的个人项目。欢迎查看源码、构建说明和测试代码。
